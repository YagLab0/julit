# Public landing

The public `/` experience presents JuLit's B2B lithium-carbonate proposition in Spanish. It links to the existing `/batches` demo and `/sign-in` without introducing a new registration, payment, or verification flow.

## Presentation contract

The approved content and implementation acceptance live in the local landing specification and Spanish copy under `.scratch/landing/`. The final section order is hero, commercial problem/solution pairs, proposed Producer–Auditor–Buyer process, conceptual Passport, participant benefits, FAQ, and dark closing composition.

The landing owns a local light semantic-token boundary. It never changes the persistent `next-themes` preference or the application's global dark-mode class. The closing section owns an inverse surface within that same boundary. Existing application providers and demo behavior remain unchanged.

Substantive content is server-rendered. Native links and FAQ disclosures do not depend on the landing motion enhancement. The enhancement adds one-time Web Animations API entrances and pointer-only press feedback, uses the installed Emil design-engineering guidance, and cancels movement for keyboard activation and reduced-motion changes. No new animation or UI primitive dependency is required.

The demo remains simulated: no USDC transfer or evidence of received funds is presented. The Passport composition contains field categories only, not a fabricated Batch, audit finding, hash, wallet, QR, or transaction. Document integrity is not proof of the report's truth or physical sample-to-shipment correspondence, and a Batch Passport is not an official EU battery passport or compliance guarantee.
